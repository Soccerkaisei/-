# 採用サイトの数値 日報（毎朝自動）

ともだちじゃぱんと同じしくみで、採用サイト（nijin.co.jp/recruit/）の数字を毎朝スプレッドシートにまとめます。

## 毎朝の日報に出るもの
- ニジアカの先生の応募数（直近28日／100）※「応募数_手入力」シートに入れた数
- 採用サイトの訪問者（昨日・直近7日・前の7日との差）
- ニジアカの先生のページ、リアル教室長のページの閲覧数
- 応募ボタン（studio.nijin.app/recruit/apply へのリンク）のクリック数と、訪問者に対する割合
- 応募ボタンが押されたページ上位5（直近28日）
- 検索：3位以内・4〜20位・21〜100位の検索語の数（前日比・1週間前比）、クリック、表示

## はじめの設定（10分）
1. 新しいGoogleスプレッドシートを作る（名前の例：採用サイト 日報）
2. 「拡張機能」→「Apps Script」を開く
3. 左の「プロジェクトの設定」（歯車）→「"appsscript.json" マニフェスト ファイルをエディタで表示する」にチェック
4. エディタに戻り、次の3つを貼る
   - `appsscript.json` の中身を、appsscript.json に上書き
   - `1_main.gs` の中身を、コード.gs に上書き
   - ＋ボタン →「スクリプト」で `2_report` を作り、`2_report.gs` の中身を貼る
5. 保存して、関数「listGa4Properties」を選んで「実行」→ 許可
   - 実行ログに GA4 のプロパティが並ぶので、nijin.co.jp のものの数字をコピー
6. `1_main.gs` の `GA4_PROPERTY_ID = ''` の '' の中に、その数字を入れて保存
7. 関数「firstRun」を選んで「実行」
   - 「日報」シートができれば完了。以降は毎朝6時台に自動で更新されます

## 毎週やること
- 「応募数_手入力」シートに、ニジアカの先生の応募を入れる（A列：日付、B列：件数。1日1行でも、週1行でもOK）
  - GA4では応募フォームの送信までは取れないため、ここだけ手入力です

## 注意
- 使うGoogleアカウントに、採用サイトのGA4と Search Console（nijin.co.jp）の閲覧権限が必要です
- Search Console の数字は2〜3日遅れて確定するので、2日前までの28日分を使っています
- 応募ボタンのクリックは、GA4の「拡張計測機能」の外部リンククリックを使っています。0のままなら、GA4の管理 → データストリーム → 拡張計測機能で「離脱クリック」がオンか確認してください
- `SLACK_WEBHOOK_URL` に Slack の Incoming Webhook のURLを入れると、日報が毎朝 Slack にも届きます
- 動いた記録は「_log」シートに残ります
