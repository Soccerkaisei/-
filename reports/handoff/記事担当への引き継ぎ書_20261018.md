# 記事担当への引き継ぎ書（2026-10-18）

「採用担当マネージャー引き継ぎ書」のセッションから、「NIJIN採用記事担当」のセッションへの引き継ぎです。
依頼者はひかるん（関 ひかる・採用担当）です。

---

## 1. 今回の依頼

採用チームは、メンバー1人ずつ、毎週次の作業を頼まれています。

| 作業 | 本数 | 締め切り |
|---|---|---|
| 新しい記事 | 10本 | **毎週水曜の定例会 8:30 まで**（理想は月曜中に終わらせる） |
| リライト | 30本 | 同上 |

- 今週（10/19〜10/21）はイレギュラーで、残りの時間が少ないです。
- 進める順番は **新しい記事が先**、そのあとリライトです（ひかるんの指示）。
- リライト30本は **こちらで選んでよい** ことになっています。

---

## 2. トークンを節約する分け方（ひかるんと決めたこと）

Rikuさんが共有した「Claudeは書く、人が送る」という考え方を、採用サイトに合わせた形です。

| | 記事担当（このセッション） | Chromeで管理画面を触るClaude |
|---|---|---|
| やること | 調べる・書く・直す・確認する。**完成品のファイルまで作る** | 完成品をWordPressに入れて保存するだけ |
| トークン | 文字だけなので少なめ | 画面を読むので多い |
| 回数 | 何回直してもよい | できるだけ1回で終わらせる |

**コツ**
1. **そのまま入れられる形で渡す。** 1本ごとに、本文のHTML・題・説明文（Yoast）・スラッグ・分類・アイキャッチ画像の案を1つのファイルにまとめる。
2. **まとめて頼む。** 1本ずつではなく、何本かまとめて頼む。
3. **Chrome側には確かめ直しをさせない。** 中身の確認はこちらで済ませる。Chrome側には「保存後、公開ページが開けるかだけ見る」と頼む。
4. **入れる直前に1つだけ確かめる。** 校長の作業が同じテーマの記事を出していないか（新規の場合）、同じ記事を直近で直していないか（リライトの場合）。

**Rikuさんのやり方（ターミナルでデプロイ）は、採用サイトには入れません。** 理由は次の3つです。
- 校長の作業と取り合いになり、上書きのおそれがある。
- ひかるんはスマホから頼むことが多い。
- サイトに受け取り口（PHPスニペット）を入れるには管理者の作業が要る。

ともだちじゃぱんのHPなど、校長の自動作業が入っていないサイトでは向いています。

## 3. リライトのやり方（校長の作業とぶつからないように）

- **記事を丸ごと貼り替えない。足す形で直す。**
  - こちらでは、足すパーツだけを作る。
    - 冒頭の結論
    - よくある質問
    - 比較の表
    - スタッフインタビューからの引用
    - 題・説明文の案
  - Chrome側は、その記事の **最新の content.raw を開いて**、決めた場所にパーツを差し込んで保存する。
  - こうすれば、校長の作業が直した部分は消えない。
- 校長の作業には「14日以内に直したコラムは触らない」決まりがある。採用チームが直した記事は、そのあと2週間は校長の作業が触らないので、取り合いになりにくい。
- **1本のリライトの基準は、校長の日報の点検項目と同じ**（ひかるんの確認済み）。
  - 題
  - 説明文
  - アイキャッチ
  - 写真3枚以上とその説明（alt）
  - 図表3つ以上
  - 事業の紹介
  - 応募への導線
  - YouTube（動画）
- **選び方**
  - 4つのまとめ記事、スタッフインタビュー、英語・スペイン語の記事は外す。
  - 校長の作業が直近2週間にリライトした記事は外す。日報の記録（下の5章のファイル）で確かめる。
  - サイトマップの更新日は使えない。10/18だけで110本が更新されていて、写真の説明などをまとめて直した分とみられる。
  - その中から、検索で4〜20位・表示が多い記事を優先する。数字はスプレッドシート「採用＿数値」の gsc_page_28d / gsc_query_28d にある。ただし、データはまだ数日分しかない。

## 6. 守ること

- **リアル教室の数（48か所・52か所）は、どこにも書かない・触らない。** どちらが正しいか決まっていないため。
- **作り話の体験談・推測の数字・確かめていない制度や金額は書かない。** 数字は公的な一次情報（文部科学省・厚生労働省・自治体など）で確かめ、出典を `p.src` で書く。
- **社員の声は、公開済みのスタッフインタビューの本人の言葉だけ。**
- **Search Console の「インデックス登録をリクエスト」はしない。** 校長の作業の担当で、ひかるん側のClaudeの使用上限にも関わるため。
- **校長への連絡・報告はしない。** ひかるんの意向。
- **説明会・資料請求などの申し込みの受け皿は作らない。**
- 4つのまとめ記事・サイドバー（custom_html-3）は、採用チームの定期作業の担当。記事作業では触らない。
- 分類（カテゴリ）は名前でIDを確かめる。親は「教育キャリアコラム」（ID 46）。小分類は次の6つ。
  - 辞めたい・迷っている
  - 先生から転職したい
  - 在宅で教育に関わりたい
  - 副業から教育に関わりたい（ID 68。前の55は使わない）
  - インターン・ボランティアとして関わる（ID 69）
  - 教室を開きたい
- このクラウド環境からは、採用サイトの wp-json（REST API）が 403 で読めない（サーバー側で止められている）。公開ページの HTML とサイトマップは読める。
