<div class="nj-rw-faq" style="border:1px solid #f3d3d3;border-radius:10px;padding:16px 18px;margin:22px 0;background:#fff;"><p style="font-weight:bold;margin:0 0 10px;">よくある質問（追加）</p><p style="font-weight:bold;margin:12px 0 4px;">Q. 部活動の顧問は、必ず引き受けなければいけませんか？</p><p style="margin:0 0 6px;">A. 中学校・高校の学習指導要領では、部活動は「生徒の自主的、自発的な参加により行われる」教育課程外の活動とされています。顧問は校長が校務として担当を決めるのが一般的で、断れるかどうかは学校や自治体の運用によります。まずは管理職に、自分の状況を具体的に伝えて相談してください。</p><p style="font-weight:bold;margin:12px 0 4px;">Q. 休日の部活動は、これから減っていきますか？</p><p style="margin:0 0 6px;">A. スポーツ庁と文化庁は、休日の部活動から段階的に地域のクラブ活動へ移していく方針を示しています。ただし進み方は自治体によって大きく違うため、勤めている自治体の計画を確かめてください。</p><p style="font-weight:bold;margin:12px 0 4px;">Q. 部活が負担で辞めたいと思うのは、甘えですか？</p><p style="margin:0 0 6px;">A. 甘えではありません。この記事のデータのとおり、中学校教員の84.9%が休日に出勤しています。先生一人の問題ではなく、働き方の仕組みの問題として考えてよいことです。</p><p style="font-weight:bold;margin:12px 0 4px;">Q. 部活動の指導経験は、転職で活かせますか？</p><p style="margin:0 0 6px;">A. 活かせます。チームをまとめる力、目標に向けて練習の計画を立てる力、大会や遠征の段取り、保護者との連絡調整は、学校の外の仕事でも強みになります。</p><p style="font-weight:bold;margin:12px 0 4px;">Q. 「部活がなければ続けられる」と感じます。どう考えればいいですか？</p><p style="margin:0 0 6px;">A. 変えたいのは教員という仕事ではなく、働き方のほうかもしれません。上の表の3つの道を並べて、どれなら自分の時間と教育への思いを両立できるかを比べてみてください。</p><p style="font-weight:bold;margin:12px 0 4px;">Q. NIJINアカデミーにも部活動はありますか？</p><p style="margin:0 0 6px;">A. 部活動はありませんが、生徒が「好き」でつながるサークル活動があります。企画や運営は生徒自身が行い、先生は伴走者として関わります。休日を返上して指導する形ではありません。</p></div>

## 3. この作業で入れるもの・注意
- パーツ4の1問目（学習指導要領の「生徒の自主的、自発的な参加により行われる」）は、文部科学省の中学校学習指導要領（総則）を開いて文言を確かめる。違っていれば、その1問だけ外す
- パーツ4の2問目（休日の部活動の地域移行）は、スポーツ庁の「学校部活動及び新たな地域クラブ活動の在り方等に関する総合的なガイドライン」を開いて確かめ、出典リンクを `p` の最後に1つ足す（確かめられなければ、その1問だけ外す）
