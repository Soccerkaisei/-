### パーツ4
- 差し込む場所：上のパーツ3のすぐあと（見出し「まとめ」の直前）

```html
<div class="nj-rw-faq" style="border:1px solid #f3d3d3;border-radius:10px;padding:16px 18px;margin:22px 0;background:#fff;"><p style="font-weight:bold;margin:0 0 10px;">よくある質問（追加）</p><p style="font-weight:bold;margin:12px 0 4px;">Q. 20代で教員を辞めるのは、早すぎますか？</p><p style="margin:0 0 6px;">A. 早すぎることはありません。20代は、未経験の分野にも挑戦しやすい時期です。大切なのは年齢より、何を変えたくて何を続けたいのかを整理してから動くことです。</p><p style="font-weight:bold;margin:12px 0 4px;">Q. 教員を1〜3年で辞めると、転職で不利になりますか？</p><p style="margin:0 0 6px;">A. 一般に、学校を卒業して数年以内の人は「第二新卒」として、経験よりこれからの伸びしろを見て採用されることが多くあります。短い期間でも、担任や行事の運営などで何をしてきたかを具体的に話せると強みになります。</p><p style="font-weight:bold;margin:12px 0 4px;">Q. 「辞めたい」と思うのは、甘えですか？</p><p style="margin:0 0 6px;">A. 甘えではありません。この記事のデータのとおり、精神疾患で休職した教員の6割以上が在職3年未満です。若手の先生がつらくなりやすいのは、個人の弱さではなく、働く環境の問題でもあります。</p><p style="font-weight:bold;margin:12px 0 4px;">Q. 心や体がつらいときは、どうすればいいですか？</p><p style="margin:0 0 6px;">A. 転職より先に、休むことを考えてください。管理職や産業医、医療機関に相談できます。厚生労働省の働く人のメンタルヘルス・ポータルサイト「こころの耳」にも相談窓口があります。</p><p style="font-weight:bold;margin:12px 0 4px;">Q. 20代の教員経験は、学校の外でも評価されますか？</p><p style="margin:0 0 6px;">A. 評価されることがあります。子どもと向き合う力、限られた時間で準備を進める段取りの力、保護者や同僚とのやりとりの力は、多くの仕事に通じます。</p><p style="font-weight:bold;margin:12px 0 4px;">Q. 教育には関わり続けたいです。どんな道がありますか？</p><p style="margin:0 0 6px;">A. フリースクール、オンラインの学校、通信制高校、教育系の企業などがあります。NIJINアカデミーのように、在宅で子どもたちの担任をする働き方もあります。</p></div>
```
