# 都道府県の記事（7本）に本文の写真を3枚ずつ入れる

千葉・愛知・兵庫・京都・広島・静岡・福岡の7本は、本文の写真の場所をあけたまま下書きにしてある。1本につき3枚、ChatGPTで作って入れる。

## やり方（1枚ごと）
1. ChatGPT（https://chatgpt.com ）で**新しいチャット**を開き、下の「プロンプト」をそのまま貼る（1チャット1枚）
2. できた写真を開いて目で確かめる（文字・ロゴ・不自然な手や顔があれば、新しいチャットで作り直す）
3. 指示書の2-4章の「ChatGPTの画像をWordPressへ渡す方法」で、メディアに入れる。ファイル名・alt・キャプションは下の表のとおり。横1600px・JPEG品質0.85程度
4. その記事の下書きの `content.raw` で、表の「入れる場所」の見出し `</h2>` の直後に、下のHTMLを入れる（`画像のURL` をメディアのURLに置きかえる）。ほかの文は触らない
5. 下書きのまま保存（公開しない）。確認リストに「写真を入れた記事と枚数」を書く

```html
<figure class="nj-fig nj-gem" style="margin:22px 0;"><img src="画像のURL" width="1600" height="900" alt="alt" loading="lazy" decoding="async" style="display:block;width:100%;height:auto;border-radius:12px;"><figcaption style="font-size:13px;color:#666;margin-top:6px;line-height:1.7;">キャプション</figcaption></figure>
```
