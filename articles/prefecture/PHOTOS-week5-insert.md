# 5週目の都道府県の写真（徳島・島根・鳥取×4枚）を下書きに入れる

ひかるさんが、保存名どおりにメディアに入れたあとに行う。

1. メディアで保存名を検索して見つける。無い画像は飛ばして、最後に書く
2. alt・キャプション・タイトル（alt と同じ）をつける
3. eyecatch は、その県の下書きの「アイキャッチ画像」に設定する
4. photo1〜3 は、その県の下書きの見出しの `</h2>` のすぐあとに、この形で入れる

```html
<figure class="nj-fig nj-gem" style="margin:22px 0;"><img src="画像のURL" alt="alt" loading="lazy" decoding="async" style="display:block;width:100%;height:auto;border-radius:12px;"><figcaption style="font-size:13px;color:#666;margin-top:6px;line-height:1.7;">キャプション</figcaption></figure>
```

- 入れる場所：photo1＝最初の見出し（「〜を検索する人が抱えている事情」）、photo2＝「忙しさ」の見出し、photo3＝「異動」の見出し。名前が少し違えば、いちばん近い見出し
- ほかの文は触らない。下書きのまま保存する（公開しない）
- 終わったら、県ごとにプレビューで4枚出ているかを確かめて、表で教えてください
