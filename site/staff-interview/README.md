# スタッフインタビュー記事（/recruit/staff/）

見本：ちひろさん記事 https://nijin.co.jp/recruit/interview-chihiro/（`reference/chihiro-wp-body.html`）
原稿：スプレッドシート「2026スタッフインタビュー」（一日のスケジュールは記事に使わない）

## 記事の型（ちひろさん記事と同じ）
1. リード文2段落（経歴・プロフィールを三人称で要約、要所に **マーカー**）
2. プロフィールボックス（丸写真・氏名よみ・肩書き・タグ）
3. Q&A 5問（段落＋写真＋ポイント囲み）
4. 読者へのメッセージ（囲み）
5. あわせて読みたい（既存記事2本）
6. 募集CTA（写真ぼかし背景＋ボタン）

配色はNIJINロゴの赤 #E8473B・オレンジ #F39A1E・黄 #F6C823（きょーこ・じゅりたろう・にけ記事と同じ）。

## 使い方
```
python3 site/staff-interview/build.py
```
- `out/<slug>.html` … WordPressの「カスタムHTML」ブロックに貼る本文
- `out/<slug>-meta.md` … タイトル・スラッグ・ディスクリプション・一覧カードHTML・**要確認事項**
- `preview/<slug>.html` … ローカル確認用（写真がない所は「写真待ち」の灰色ボックス）
- `img/<名前>/` … WordPressにアップロードする写真（縮小済み）
